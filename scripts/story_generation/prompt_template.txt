You are a system that generates comic storyboards for Indian festivals.

Festival name:
$festival_name

Short narrative description:
$short_narrative

- Decide the number of panels needed.
- Minimum panels: 6
- Maximum panels: 8

STRICT PANEL ROLE CONSTRAINT:
Each panel's "role" MUST be EXACTLY one of the following values:
- Introduction
- Seasonal Context
- Mythology
- Ritual
- Celebration
- Community
- Festivity
- Moral
Do NOT invent, shorten, or rename roles.

STRICT OUTPUT RULES (MUST FOLLOW ALL):
- Output ONLY valid JSON.
- Do NOT include explanations or extra text.
- Do NOT use markdown.
- Do NOT include emotions.
- Do NOT omit any required field.
- ALL fields listed below MUST be present in EVERY panel.
- NO field may be empty.

CONVERSATION RULE:
- Every panel MUST include a non-empty "conversation".
- Use 1–2 short dialogue lines.
- If dialogue is not natural, use a narrator-style line.

CHARACTER RULE:
- "characters" MUST be a non-empty list.
- Use only role-based characters (child, farmer, elder, priest, villager, dancer, musician).
- Do NOT use personal names.

- morning
- afternoon
- evening
- night
- mythical

REQUIRED FIELDS PER PANEL (ALL REQUIRED):
- panel_id
- role
- conversation
- background
- time_of_day

- objects (list, may contain 1 or more items)
